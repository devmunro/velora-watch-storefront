# Velora

Velora is a luxury watch storefront built with Astro and TypeScript. The public website, customer account area, commerce services, and protected administration area live in one maintainable codebase.

## Local development

1. Install dependencies with `pnpm install`.
2. Copy `.env.example` to `.env` and provide development credentials.
3. Start the website with `pnpm dev`.

Use `pnpm typecheck` and `pnpm build` before committing changes.
